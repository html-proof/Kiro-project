3. **Edit your emulator**
4. **Increase Internal Storage** to at least 4GB
5. **Save and restart emulator**

Then run:
```bash
flutter run
```

1. **Enable USB Debugging** on your phone
2. **Connect via USB**

## 🆘 Troubleshooting:

### "Insufficient Storage" on Emulator
- Increase emulator storage in Android Studio
- Or use Windows desktop: `flutter run -d windows`
- Or use physical device

### "Build Failed"
```bash
flutter clean
flutter pub get
flutter run
```

### "Firebase Error"
- Download `google-services.json` from Firebase Console
- Place in: `android/app/google-services.json`
